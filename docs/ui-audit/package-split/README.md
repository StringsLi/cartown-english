# 分包瘦身与独立儿歌电台（2026-10-04）

## 本次改动

- 8 首原创儿歌迁移到 `pkg-music`，儿歌电台独立页面保留歌词、播放状态、停止与重播、对应主题和亲子任务入口。
- 六个汽车页面与 30 张真实 JPEG 车辆图迁移到 `pkg-cars`，存储键和进度规则不变。
- 保留原 `pkg-learning/car-*` 六条路由，以替换当前页的方式跳转，保留编码后的查询参数，失败后可手动重试。旧 `playground/index?tab=chants` 自动进入新电台。
- 包内音频和 CachedImage 的资源先等待微信 `wx.loadSubpackage` 成功，再开始使用。并发合并，成功缓存，失败/超时可重试，迟到回调不能开始已取消的播放。
- 学习页在 Wi-Fi 下预加载儿歌包；儿歌图片有自己包内的八张小图。
- 工程门槛增加任意两个分包之间的同步 JS 依赖检查，以及总包低于 20 MiB 检查。原主包 1.5 MiB、单分包 2 MiB、单媒体 200 KiB 门槛不变。
