# 听音游戏与答题反馈优化 · 2026-10-13

## 本轮变更

- 颜色汽车、车标、红绿灯动作和星球找图统一先听本题提示，再开放答案。等待声音、播放失败和静音不计为听过；静音时提示去家长中心打开音量。
- 切后台、离开页面、切题、重玩和车标切换学习模式会清除听音状态。已经取消或上一题的声音回调不能解锁新题。
- 颜色和车标答对后显示绿色高亮与“✓ 找到了”，交通动作显示正确动作勾选；错误反馈改为中文鼓励语。车标听音按钮移到选项上方。
- 禁用卡片保留页面配色，星球卡片不会被系统覆盖成白底；通用大按钮保留各自配色并以透明度区分禁用状态。存储重试组件改用类选择器，兼容微信组件样式约束。
- 星球提示按钮在小屏保持至少 44px，答对后仍可重播本题提示。
