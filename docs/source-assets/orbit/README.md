# 太阳系图片来源

源仓库：https://github.com/ryh842487118-bot/orbit

使用 assets 中的太阳、水星、金星大气、地球日间、月球、火星、木星、土星、天王星和海王星纹理。作者 Solar System Scope；原始图链接与 CC BY 4.0 授权见 CREDITS.md。

小程序图片由原纹理缩小为 768×384 并压缩为 JPEG（quality 68）。圆形裁切、明暗和土星环在界面中绘制，属于科普视觉示意。图片不是未经加工的航天器实拍。地图中的距离、大小和运动速度不按真实比例。

科普内容参考 NASA：
- https://science.nasa.gov/solar-system/planets/
- https://science.nasa.gov/venus/venus-facts/
- https://science.nasa.gov/saturn/facts/
- https://science.nasa.gov/moon/facts/

英语音频使用项目已有 Piper / en_US-ljspeech-high 声线生成，工具和模型不进入发布包。
